引擎与边界

本机采集recap collect

读 git 与 notes，写入 PowerContext。

本机镜像recap index

把 artifact 复制进嵌入式 seekdb。

导出recap seed

生成 web/seed.json，带原始引用。

云端入库POST /api/import

校验后写入 entries，按 cite 幂等。

组合与检索GET /api/report

从库里组合周报、执行检索。

这里真实承重的部分

  • 写入表单提交经服务端校验后落库，重放同一个幂等键不会多出第二条。
  • 组合周报按类型分桶、逐条挂引用，没有出处的句子不会出现在报告里。
  • 检索关键词、日期窗、类型过滤在库内数据上执行，返回命中数与扫描数。

它不是什么

  • 不调用大模型组合是规则装配，和 CLI 一样可复现。
  • 不做向量检索混合检索与裸 SQL 演示在本机的 seekdb 里跑（recap search --raw-sql）；云端没有 embedding 与全文索引，检索是库内扫描，上限最近 1000 条。
  • 不是多租户写入需要 Qoder 登录，但痕迹板对同站所有登录者可见；私有内容请留在本机。

数据与服务

数据来自站点数据库；源码与运行说明见交付仓库的 qoder/ 目录。
